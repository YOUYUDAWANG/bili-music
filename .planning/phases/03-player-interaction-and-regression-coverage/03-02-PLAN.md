## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user toolbar tap -> player managers | Toolbar buttons invoke favorites, cache, quality, lyrics, and MV behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | recommendation page tap state | mitigate | Preserve `suppressNextRecommendationRefresh` and run `RecommendationSchedulingTests`. |
| T-03-06 | Denial of Service | center-page cover layout | mitigate | Keep `CachedAsyncImage` target sizes and avoid additional artwork preloading. |
| T-03-07 | Elevation of Privilege | disabled lyrics/MV controls | mitigate | Disabled controls remain inactive and labeled; unavailable states do not execute sheet or MV actions. |
| T-03-08 | Spoofing | toolbar active states | mitigate | Pair color with icon/label/accessibility value so unavailable or active state is not color-only. |
| T-03-SC | Tampering | package installation | accept | No package-manager install occurs in this plan; no external dependency is added. |
</threat_model>
