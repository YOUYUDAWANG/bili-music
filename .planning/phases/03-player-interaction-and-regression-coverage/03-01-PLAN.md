<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user touch -> SwiftUI gesture state | Untrusted drag velocity/distance can trigger disruptive player presentation. |
| player UI -> playback engine | UI actions must not insert blocking work before playback requests. |
| artwork view -> image cache | Larger visible surfaces must not decode or retain unbounded artwork. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service | `SystemMiniPlayer` drag path | mitigate | Gate open/cancel decisions through `PlayerGesturePolicy` and cover shallow-drag cancellation in unit/UI tests. |
| T-03-02 | Denial of Service | `RootView` transition animation | mitigate | Respect `accessibilityReduceMotion`, avoid expensive blur/physics, and keep animation state-local. |
| T-03-03 | Denial of Service | playback startup from player UI | mitigate | Run `PlaybackCriticalPathTests` and avoid awaited enrichment in transition handlers. |
| T-03-04 | Denial of Service | full-player artwork cache | mitigate | Run `ImageCacheTests`; continue target-size `CachedAsyncImage` behavior. |
| T-03-SC | Tampering | package installation | accept | No package-manager install occurs in this plan; no external dependency is added. |
</threat_model>
