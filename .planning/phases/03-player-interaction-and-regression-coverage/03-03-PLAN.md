## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user drag -> dismiss/page/scrub policy | Gesture input can accidentally disrupt playback UI if ownership is ambiguous. |
| list scroll -> full-player container | Scroll gestures on queue/recommendation pages cross a boundary where the full-player container also observes drags. |
| progress scrub -> playback engine | Scrub changes playback time and must not trigger unrelated page/minimize gestures. |
| regression suite -> source changes | Source changes can weaken previously fixed playback/search/recommendation/image behavior. |
