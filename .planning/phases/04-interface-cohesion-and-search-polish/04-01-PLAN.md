# Phase 04-01: Interface Cohesion and Search Polish

## Phase Goal

Make the daily UI feel calmer and more coherent while preserving the v1 playback, search, recommendation, and gesture guardrails.

## Scope

- Replace the previous pink accent with a calmer Bilibili blue-cyan accent and shared row selection colors.
- Remove visible search mode scopes and the separate MV search surface from the primary search chrome.
- Keep search focus local: empty focused search should show history or an empty-history state only.
- Make search result rows easier to tap and visually consistent with other music rows.
- Keep display-title cleaning conservative so only high-confidence structured parses change list titles.
- Rebalance the player toolbar as a grouped Apple Music-like action area without reopening the bottom-gap problem.

## Acceptance Criteria

- Search focus does not start remote work and does not show Music/MV/expanded scope chips.
- Search results render `最佳匹配` plus `音乐结果`, not a separate `音乐视频` section.
- Shared rows and cards use the same selected/pressed treatment and the blue-cyan accent.
- Toolbar actions remain in one compact grouped control and the modern dense-player layout gate passes.
- Noise-only title cleanup such as `【4K修复】晴天 Official MV` stays unchanged for UI display, while structured titles still parse.
