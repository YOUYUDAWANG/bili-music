# Phase 06-04 — Luna 排练、缓存与 `.lyricstage`

## 目标

让 Luna 作为显式排练导演生成可验证 Recipe，并把演出保存为不含音频的可携带包；正式播放不依赖网络。

## Task 1 · 显式 Luna 排练

- [ ] 复用现有 V4 typed recipe 语义；只允许 capability/density 高层提示，不输出坐标、绝对 reveal 时间或歌词文本。
- [ ] 通过同源服务端代理请求 Luna；浏览器不持有长期密钥。
- [ ] 只在用户点击生成/重新生成时联网；生成期间本地 fallback 继续可播。
- [ ] 双端校验、单坏 scene 局部 repair/drop、低有效率整曲 fallback。

## Task 2 · 本地缓存与身份

- [ ] IndexedDB 分开缓存 audio facts、direction 与 prepared identity。
- [ ] identity 覆盖 lyrics/audio/director/compiler/capability/font/viewport 的正确层级。
- [ ] 切歌、取消、清除与旧请求由 generation identity 隔离。
- [ ] 刷新后可恢复已校验 Recipe；Luna 超时、invalid、degraded 不污染缓存。

## Task 3 · `.lyricstage` 演出包

- [ ] 导出 manifest、lyric document、audio facts、Recipe 与字体需求；默认不含音频与 PreparedStage。
- [ ] 导入时重新按当前 renderer/capability/font/viewport 编译。
- [ ] 坏包只返回可操作错误，不覆盖源文件、缓存或当前演出。
- [ ] 开演前 preflight 音频、字体、歌词、Recipe 与 fallback；开演后不再请求 Luna。

## 验证

- [ ] Luna 超时/断网/invalid/degraded 不丢歌词、不阻塞播放。
- [ ] 同一请求命中缓存；刷新后恢复方向；关闭网络后已排练歌曲仍能完整演出。
- [ ] 演出包在 Mac/Windows 上保持相同文本、时间、scene 语义和 identity；字体像素允许不同。
- [ ] 本地音频、PCM、Cookie、模型密钥与长期 Bearer 不进入包或浏览器持久化。

## 完成定义

用户可以排练、显式生成、缓存与迁移一份演出，但仍在单窗口中操作；正式第二屏 Show Mode 留给 06-05。
