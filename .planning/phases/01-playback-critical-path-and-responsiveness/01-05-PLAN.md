## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote image URL -> decoded UIImage cache | Untrusted remote image bytes become app memory objects. |
| App lifecycle notifications -> cleanup | Background and memory-warning events trigger resource release while playback continues. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12 | Denial of Service | `ImageLoadCoordinator` | mitigate | Downsample before cache insertion, preserve coalescing, and keep bounded `NSCache` limits. |
| T-01-13 | Information Disclosure | image/media headers | mitigate | Preserve existing `BiliClient.headers` behavior without adding diagnostic logging of auth or request headers. |
| T-01-14 | Denial of Service | memory/background cleanup | mitigate | Release reloadable decoded images on background/memory pressure without clearing playback state. |
| T-01-SC | Tampering | package installs | accept | No package-manager install is planned. |
</threat_model>
