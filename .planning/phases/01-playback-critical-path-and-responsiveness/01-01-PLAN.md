| XCTest fixture data -> app code | Test-only values exercise production code paths without real account secrets. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `PlaybackDiagnostics` | mitigate | Emit checkpoint names, bvid/cid/source kind, quality, and timing only; tests assert no auth headers or private stream URL values are present. |
| T-01-02 | Repudiation | `PlaybackDiagnostics` | mitigate | Preserve ordered tap-to-first-play checkpoints so playback regressions can be attributed to source resolution, item creation, play request, or first playing state. |
| T-01-SC | Tampering | package installs | accept | No npm, pip, cargo, SwiftPM, CocoaPods, or Carthage install is planned; Package Legitimacy Audit says no external packages. |
</threat_model>
