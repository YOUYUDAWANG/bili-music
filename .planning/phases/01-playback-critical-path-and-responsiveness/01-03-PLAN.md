<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User search focus/typing -> network layer | Private user intent could become a Bilibili request if focus/typing triggers search. |
| Local history/cache -> Search UI | Local playback and cache metadata is rendered in a search surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Information Disclosure | `SearchView.onChange` | mitigate | Network starts only on explicit submit/retry/broaden/load-more; unit tests assert focus/typing performs no Bilibili work. |
| T-01-07 | Denial of Service | search focus path | mitigate | Remove typing debounce network fan-out and image-heavy preloading from focus/typing. |
| T-01-08 | Spoofing | local suggestions | accept | Suggestions are local history/cache rows already owned by the app; no auth or account boundary changes in this plan. |
| T-01-SC | Tampering | package installs | accept | No package-manager install is planned. |
</threat_model>
